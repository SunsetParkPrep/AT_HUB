# Assistive Technology Hub

Files in this repo (all in the main folder, no subfolders):

    index.html         the website
    tutorials.xlsx     one row per tool (name, category, tutorial link, description)
    xlsx_full_min.js   the library that reads the Excel file. Leave it alone.

## Add a tutorial
Open tutorials.xlsx, add a row at the bottom, save. Then in this repo tap Add file, Upload files,
choose the updated tutorials.xlsx, and Commit. The site updates in 1-2 minutes.
- Category: same category = same group on the site. A new name makes a new group.
- Tutorial link: paste the full address starting with https://

## Students (optional)
If a file named students.xlsx is in this repo, the site shows a student list.
GitHub Pages is public, so only add students.xlsx if your school has approved it.
